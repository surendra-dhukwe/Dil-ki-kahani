# ❤️ Dil ki Baate - Shayari Platform

Ek simple aur beautiful web app jaha users apni **shayari, thoughts aur dil ki baate** share kar sakte hain.

---

## 🚀 Features

- ✍️ Create Post (Title + Description + Content)
- 👤 User system (auto suggest + create user)
- 📜 All posts feed
- 🔍 Search by name
- 🧑‍🤝‍🧑 Writers list (click → show their posts)
- 💬 Comments system
- ❤️ Double click heart animation
- ⚡ Fast & smooth UI
- 🎨 Professional modern design (Glass UI)

---

## 🛠️ Tech Stack

### Frontend:
- HTML
- CSS (Advanced UI + Animations)
- JavaScript (Vanilla)

### Backend:
- Node.js
- Express.js

### Database:
- MySQL
